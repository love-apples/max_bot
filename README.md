# Max Bot

Бот для Max API с функционалом управления чатами: система репутации, предупреждений и модерации.

## Возможности

- 📊 **Система репутации** - изменение репутации через ответ на сообщение с `+` или `-`
- ⚠️ **Система предупреждений** - админы могут выдавать предупреждения пользователям
- 🚫 **Система киков** - исключение пользователей из чата с причиной
- 🛡️ **Антиспам** - автоматическое удаление спам-сообщений (лимит: 5 сообщений за 10 секунд)
- 👋 **Приветственные/прощальные сообщения** - настраиваемые тексты при добавлении/удалении пользователей
- 📋 **Информация о пользователях** - просмотр статистики (варны, кики, репутация)
- 🔧 **Техническая информация** - детальная информация о пользователях из API

## Требования

- Python 3.12+
- MongoDB 7+
- Docker и Docker Compose (для запуска через Docker)

## Установка

### Вариант 1: Локальная установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/love-apples/max_bot.git
cd max_bot
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе `example.env`:
```bash
cp example.env .env
```

4. Заполните `.env` файл:
```env
BOT_TOKEN=ваш_токен_бота
BOT_ADMINS=123456,789012

MONGO_NAME=max_manager_bot
MONGO_HOST=localhost
MONGO_PORT=27017
```

5. Запустите MongoDB локально или используйте Docker:
```bash
docker run -d -p 27017:27017 --name mongo mongo:7
```

6. Запустите бота:
```bash
python bot.py
```

### Вариант 2: Docker Compose

1. Клонируйте репозиторий:
```bash
git clone https://github.com/love-apples/max_bot.git
cd max_bot
```

2. Создайте файл `.env`:
```bash
cp example.env .env
```

3. Заполните `.env` файл:
```env
BOT_TOKEN=ваш_токен_бота
BOT_ADMINS=123456,789012

MONGO_NAME=max_manager_bot
MONGO_HOST=mongo
MONGO_PORT=27017
```

4. Запустите через Docker Compose:
```bash
docker compose up --build -d
```

5. Просмотр логов:
```bash
docker compose logs -f bot
```

6. Остановка:
```bash
docker compose down
```

## Конфигурация

### Переменные окружения

Создайте файл `.env` в корне проекта:

```env
# Токен бота (обязательно)
BOT_TOKEN=your_bot_token_here

# Список администраторов (ID пользователей через запятую)
BOT_ADMINS=123456,789012

# Настройки MongoDB
MONGO_NAME=max_manager_bot
MONGO_HOST=localhost  # или 'mongo' для Docker
MONGO_PORT=27017
```

## Команды бота

### В чатах

- `/start` или `/menu` - меню бота
- `/info [ID]` - получить информацию о пользователе из БД (варны, кики, репутация)
- `/tech_info [ID]` - получить техническую информацию о пользователе из API
- `/warn` - выдать предупреждение (ответом на сообщение, только админы)
- `/kick` - исключить пользователя из чата (ответом на сообщение, только админы)
- `+` или `-` - изменить репутацию пользователя (ответом на сообщение)

### В личных сообщениях

- `/help` - справка

## Система репутации

Репутацию можно изменить, ответив на сообщение пользователя текстом:
- `+` или `+ причина` - повысить репутацию
- `-` или `- причина` - понизить репутацию

Репутацию можно изменить только раз в час для одного пользователя в одном чате.

## Структура проекта

```
max_bot/
├── bot/                    # Основная логика бота
│   ├── filters/           # Фильтры для обработчиков
│   ├── handlers/          # Обработчики команд и событий
│   ├── middleware/        # Middleware (антиспам, события)
│   ├── templates/         # Шаблоны сообщений
│   └── utils/             # Вспомогательные функции
├── core/                   # Ядро приложения
│   ├── bot.py            # Инициализация бота
│   ├── logger.py         # Настройка логирования
│   └── mongo.py          # Подключение к MongoDB
├── db/                     # Работа с базой данных
│   ├── models.py         # Модели данных
│   └── crud.py           # CRUD операции
├── maxapi/                 # Библиотека Max API
├── bot.py                  # Точка входа
├── config.py              # Конфигурация
├── compose.yml            # Docker Compose конфигурация
├── bot.dockerfile         # Dockerfile для бота
├── requirements.txt       # Зависимости Python
└── .env                   # Переменные окружения (создать самому)
```
